# 全局说明

可以通过设置webhook来实现订单创建、用户信息修改、用户支付等事件的通知。

## 目前支持

具体参考部署应用程序的该页面（/admin/develop/notificationHook）

## 请求说明


请求方式：`POST`

Header 参数说明：

| 参数 | 类型 | 示例 | 说明 |
| --- | --- | --- | --- |
| Content-Type | string | `application/json` | 固定值 |
|SunStore-Signature|string|`ts=时间戳;h1=签名值`|签名值时间戳，用作数据校验|


## 响应说明

http状态码返回 `200` 则代表成功。如果返回其他状态码，则视为未成功收到，将触发[重试机制](#retry)

## 重试机制 {#retry}

失败后，一共尝试次数为20次（具体次数暂时不准确，后续随时调整）。
